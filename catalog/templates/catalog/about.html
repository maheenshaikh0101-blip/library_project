ABOUT THE PROJECT

The Book Library

A Django web application built step by step for the Web Development using Python practicals.

What it includes

  • Catalog: CRUD operations on books using the Django ORM and SQLite.
  • Admin: data management through the Django Admin panel.
  • Accounts: signup, login and logout with @login_required and CSRF protection.
  • Notes: user-specific notes with ModelForms and session data.
  • API: a REST API built with Django REST Framework.
  • Deployment: hosted online on Render.
